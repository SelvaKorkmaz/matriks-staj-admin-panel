# Bootstrap Admin Panel

Bu proje, yaz stajı kapsamında geliştirilmiş responsive bir Bootstrap Admin Panel uygulamasıdır.

## Özellikler

- Responsive tasarım
- Bootstrap 5
- jQuery UI Datepicker
- Mobil Offcanvas Menü
- Dashboard
- Sidebar Menü
- Font Awesome ikonları

## Teknolojiler

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
